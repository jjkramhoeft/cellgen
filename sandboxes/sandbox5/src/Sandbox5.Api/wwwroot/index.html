Sandbox 5 · Map service

The cellgen world map, generated on the server by a C# domain model and delivered through a REST API: map images as PNG tiles and map data as JSON. This page is a small viewer on top of that API.

Map

  • Drag to pan, scroll or + − to zoom, click to inspect a point.
  • 0 origin · arrows pan · R random seed · 1–9 colour mode · [ ] previous / next colour mode.
  • B zone borders · N patch borders · V rivers · C locations · P travel network · H hillshade · Esc clear the selection.

API

  • GET api/map/tiles/{z}/{x}/{y}.png and api/map/image.png: map images.
  • GET api/map/at?x=&y=: everything at a point (what the inspector shows).
  • GET api/map/regions/{i},{j}, …/rivers, …/lakes, …/locations, …/travel: one region's data.
  • GET api/map/structure and api/map/network: the exports documented in docs/.
  • The full list: api.
